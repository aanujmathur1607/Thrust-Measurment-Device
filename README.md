# Low-Cost Thrust Measurement Stand

**Project Status: In Progress**

## Overview

This project focuses on the design and development of a low-cost, portable thrust measurement stand for experimental propulsion testing.

The system is intended to measure the thrust generated by a motor and propeller assembly using a load cell and an HX711 load-cell amplifier. An ESP8266 NodeMCU serves as the microcontroller for acquiring sensor readings.

The long-term objective is to develop a reliable experimental setup that can record thrust data, calculate total impulse from thrust measurements over time, and support engineering analysis of propulsion performance.

## Objectives

- Design a low-cost and portable thrust measurement stand.
- Measure force using a load cell.
- Interface the load cell with an HX711 amplifier.
- Acquire sensor readings using an ESP8266 NodeMCU.
- Develop a software workflow for recording and analysing measurements.
- Calculate impulse from thrust-versus-time data.
- Investigate measurement accuracy, repeatability, and calibration.

## System Architecture

Load Cell → HX711 Amplifier → ESP8266 NodeMCU → Computer → Data Analysis

The load cell measures the force produced by the test assembly. The HX711 conditions the sensor signal, and the ESP8266 is intended to acquire the readings for subsequent processing and analysis.

## Engineering Principles

### 1. Thrust Measurement

The load cell measures force along the direction of the applied load.

The measured force is expressed in newtons (N).

Accurate measurements require appropriate sensor calibration, correct mechanical alignment, and minimisation of unwanted forces and vibrations.

### 2. Impulse Calculation

Impulse is the integral of thrust over time.

J = ∫ F(t) dt

Where:

- J = impulse, measured in newton-seconds (N·s)
- F(t) = thrust as a function of time, measured in newtons (N)
- t = time, measured in seconds (s)

For discrete measurements, impulse can be estimated numerically using the trapezoidal rule:

J ≈ Σ [(Fᵢ + Fᵢ₊₁) / 2] × (tᵢ₊₁ − tᵢ)

This calculation requires reliable, time-stamped thrust measurements.
